# 冻结的 Agent 开发历史——仅用于训练

研究包最初会在下载后立即打开工作区，后来发现校验和可能尚未验证，Codex Host 版本也可能与实验限定版本不同。团队因此引入 `orientation gate`：先验证发布包摘要，再确认原生 Codex Host，最后才进入不计分练习。

这个 Gate 只证明本地材料与声明版本一致，并且当前 Host 能承载实验交互。它不能证明参与者已经理解后续场景，也不能证明 Pointable Context 能提升效率。通过 Gate 后的下一步是完成一次不计分的选取、展开和答题练习。

任务：选中 `orientation gate`，打开它的上下文，并提交一个训练答案。本轮不计分。

- `TRAIN-A`: 在不计分练习之前验证发布包和实验 Host。
- `TRAIN-B`: 把环境检查当作后续答案必然正确的证明。
- `TRAIN-C`: 因为工作区能够打开，所以跳过 Host 和发布包检查。
