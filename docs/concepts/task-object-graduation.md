# Task Object Graduation

## 它是什么意思

把当前任务中仍为 `partial` 的临时对象，转换为有稳定身份、可复验来源并能跨任务继续使用的仓库制品；没有持续价值的对象则显式退役。

## 为什么现在出现

Task-local Dynamic Object 已在真实 Codex Chat Lane 中完成出现、原位读取、内容更新、身份替代和历史查询验证，说明它已从临时实现想法转为后续开发会持续引用的产品概念。

## 它不是什么

固化不是自动摘要、Chat 扫描或“出现次数足够多”后的自动晋升，也不把 Agent 声明升级为测试事实；没有非循环 workspace evidence 的对象仍只能保持 `partial`。

## 所处流程

- 当前任务显式登记 `partial` 对象
- 通过原位读取、revision、替代或退役校准其真实价值
- 当前：把稳定且需要跨任务复用的对象写成证据绑定制品
- Artifact Check 通过后退役临时身份，并由仓库制品继续提供上下文
