# Pilot

## 它是什么意思

正式实验前的小规模可用性试跑，用来发现任务、卡片和研究流程中明显的理解障碍。

## 为什么现在出现

Pointable Context 已完成原生 Chat Lane 的技术链路与自动延迟基准，但还不知道人是否能从卡片中更快、正确地理解信息；因此正式效率实验前要先检查研究流程是否可用，并估计结果波动。

## 它不是什么

Pilot 可以发现流程缺陷并帮助规划正式样本量，但不能证明产品已经显著降低信息获取时间或 Chat Turn 数。

## 所处流程

- 原型与技术门禁完成
- 当前：Pilot，约 8–12 人检查理解任务与流程
- 根据错误与方差确定正式样本量
- 正式受控效率实验

## 证据

> Define the formal sample size only after a non-inferential usability pilot estimates variance. A pilot of roughly 8–12 participants may find workflow defects but must not be used to claim significance.
