# Long Task Dogfood

## 它是什么意思

在真实、持续推进的软件开发任务中日常使用 Pointable Context，借由自然发生的延迟重返、跨会话恢复、状态漂移和任务交接，检查用户能否依靠原位卡片重新建立正确的项目理解。

## 为什么现在出现

P-C 微型心智模型、动态刷新和当前精确 Codex build 已完成资格验收；下一步需要在信息量、时间跨度和项目变化都真实存在的任务中观察对象选择、信息结构与恢复路径是否够用。

## 它不是什么

长任务 Dogfood 不是短任务 A/B 实验，不自动采集 Chat 或文件内容，也不能单独证明效率显著提升、跨版本兼容或所有重要对象都已被覆盖。

## 所处流程

- P-C 信息结构、动态刷新与当前构建资格完成
- 当前：在真实长任务中持续使用，并只记录自然发生的关键观察
- 延迟重返、跨会话、状态漂移或交接发生时复验对象与证据
- 场景和测量流程稳定后重新冻结效率实验

## 证据

> 开展长周期 dogfood，重点观察延迟重返、跨会话恢复、状态漂移和任务交接；当前显式 Coverage 随 Artifact Check 与首个原生理解验收扩展到七个期望对象；
